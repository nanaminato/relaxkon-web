# 资料空间

资料空间是同一账户跨设备可访问的私有文件列表。它直接读取服务端，不把整个文件库打包进聊天同步请求，也不在浏览器持久缓存文件内容。

- 从侧栏进入「资料空间」。未登录时先登录。
- 可上传、搜索、筛选、下载、重命名和删除文件。默认限制以服务端返回为准（默认单文件 10 MiB、总容量 100 MiB、最多 100 个文件）。
- 页面进入、重新获得焦点以及可见且空闲时每 30 秒刷新；也可手动刷新。它不是离线实时协作编辑器。
- 重命名和删除携带文件版本。其他设备已修改时显示冲突并刷新，不覆盖新版本。
- 删除需要明确确认，会影响所有设备的资料空间，但不会移除以前已复制到对话的附件。
- 下载使用带认证的请求获取 Blob，临时浏览器下载地址及时释放；没有公开文件 URL。
- 分享对话不分享整个资料空间。聊天附件使用遵循现有对话流程，向模型发送之前仍由用户选择。

## 连接与错误

`LibraryService` 使用 `ServiceProvider.apiUrl` 下的 `/api/library`，沿用现有 JWT 拦截器。上传是 multipart `file`，不是 Base64 JSON。无权限、文件消失、版本冲突、大小/数量/容量限制分别显示明确提示。网络失败时不会自动重试写入；先刷新确认状态。

账户切换/退出立即清空页面文件元数据，取消在途请求的订阅，拒绝旧会话返回值和旧文件选择器结果。页面关闭后的不确定上传可能已被服务端接收，重新进入后以服务端列表为准。

## 验证

自动化测试覆盖 API 路径/表单/版本参数、筛选、退出和切换账户的迟到结果、文件选择器跨账户返回、重复写入阻止、删除确认、版本冲突及本地大小拦截。测试不调用真实用户账户或上传实际资料。
