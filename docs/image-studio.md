# 图像工作室

模型选择仅保留 GPT Image 2.5 Flare/Sunburst 和 2.6 Flare/Sunburst。默认 2.6 Flare；实际调用需要后端已配置对应逻辑模型及供应商路由，页面选择不会自动开通模型。

桌面端为创作/结果两栏，手机端为纵向滚动布局，支持提示词示例、高级设置、GIF 动画参数、SVG 单张输出、图片预览与下载。GIF 的尺寸控件与请求均固定为 auto。生成失败可重试；结果保存/同步失败单独重试，不会重新生成图片。

已移除 DALL·E、GPT Image 2 及以下的选项、旧参数和创建服务。APIMart 旧创建页面仅提供 2.0 模型，因此旧地址跳转至当前工作室；历史作品和任务结果查询保留。SVG 仅用 img 展示，不把供应商返回的 XML 注入页面。

验证：101 项 ChromeHeadless 测试、6 项国际化检查、应用与测试 TypeScript、生产构建通过。实际浏览器检查了桌面与 390px 手机宽度、模型列表、GIF 限制，手机端无横向溢出。未发送真实付费生成请求。

官方参数依据见后端仓库 docs/image-generation.md。
